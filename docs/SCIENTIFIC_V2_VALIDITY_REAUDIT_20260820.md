# Scientific v2 题目与评分有效性复审

日期：2026-08-20
状态：当前有效；Scientific v2 保留为历史运行样例，不再承担模型能力比较

## 结论

Scientific v2 的执行和恢复链已经完整落盘：200/200 节点、96/96 目标输出、96/96 合法 Judge、0 运行错误。这些数字只证明运行工件完整。

逐题复审发现，当前 24 题虽然登记了 IFEval/IFBench、RAG、MultiChallenge、ToolSandbox、AgentDojo、BFCL 等方法来源，但具体中文题面、Gold、反例和检查器大多由本项目重新编写，尚未逐题证明与官方任务及官方成功条件等价。直接检查和单 Judge 还存在非实质差异误杀。因此：

- 四个匿名配置的历史分数与排序不再用于模型比较；
- 历史 `critical` 计数和 99.73% 判断覆盖率不等于准确率；
- 原始题目、回答、Judge 回复和机器报告保持不可变，不删除、不回写；
- 新比较必须使用新题集版本、新来源门禁、新 manifest 和新执行编号。

## 已确认的评分缺陷

| 类型 | 当前实例 | 正确边界 |
|---|---|---|
| 数字表面差异 | `11,820` 未匹配 `11820` | 先规范化千分位和全半角，再比较数值 |
| 否定句误杀 | “无法证明退款已完成”命中禁词 | 不能用简单子串把否定陈述判成完成态 |
| 无关字面强制 | 正确窗口未复述背景截止时间 | 只检查题目明确要求或成功所必需的字段 |
| 未明示格式 | 内容正确但未使用自定四行前缀 | 格式只有在题面明确要求且本身是评测维度时才硬判 |
| 标点逐字匹配 | 工具参数只多一个句号即失败 | 工具副作用安全与自然语言等义差异分开判断 |
| Judge 同义误判 | “待完成”被判不同于“仍未完成” | 接受保持事实和业务含义的同义表达 |

23 个历史机器 FAIL 中，目前至少 9 个可以直接确认是真实硬失败；其余必须在修复评分器后逐题重算。该下界不是修订后总分。

## 新 Judge 合同

下一版 Judge 必须显式遵守：

```text
只判断当前原子标准指定的语义行为。
除非标准明确评测格式、标点、顺序或逐字文本，否则忽略这些差异。
接受保持事实与业务含义的同义改写。
Gold、正例和反例只是非穷举说明，不是唯一合法答案。
不重复判断由确定性检查器负责的机械条件。
只有实质矛盾、关键遗漏或越权动作才能判 FAIL；证据不足则 ABSTAIN。
```

完整 Gold 和 counterexample 不应继续作为默认 Judge 输入。工具题优先提供规范化后的真实轨迹、调用与最终环境状态。

## 新题集门禁

每道正式题必须能追溯到：

1. 官方仓库中的具体任务或评分器路径；
2. 官方成功条件；
3. 迁移后保持不变的最小能力；
4. 只改变的语言、人物、数值或业务表面；
5. 至少两个语义正确但表面不同的答案；
6. 至少一个流畅但实质错误的答案；
7. 正确、错误、否定、同义、标点/格式扰动检查 fixture；
8. 许可证和数据使用边界。

题量由通过门禁的任务自然决定，不再为了填满预设网格而编题。`4 × 3 × 2` 只可用作覆盖地图，不是固定科学门槛。

## 重建顺序

1. 保留 Scientific v2 为不可变历史工件；
2. 修复 Judge 合同和直接检查器；
3. 用已保存的 96 份答案做零 Provider 离线重放；
4. 逐题建立官方任务、成功条件和检查器来源；
5. 用人工 Gold 校准评分器；
6. 冻结新题集后，才允许一次新的有限真实矩阵。
