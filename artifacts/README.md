# 公开证据与本地运行工件

`artifacts/` 默认保存运行日志、逐题节点、恢复清单和报告。绝大多数内容是本机运行工件，不进入公开仓库，避免把重复中间结果、调试日志或潜在环境信息带进 Git 历史。

公开仓库只保留一份经过敏感词扫描的身份盲机器最终报告：

- `scientific_v2/executions/scientific-v2-20260804-a-recovery-4/machine_final_report.json`
- 源文件 SHA-256：`908D51899324F1C286F42A9EADF988D28EE2E058FA827F4645D5F38FFC91A4D0`
- 该报告不含实际模型名、API Key、Base URL 或 Provider 身份；配置仍以项目内部逻辑槽位表示。

它只能证明本项目在已冻结 24 题、四个应用配置、当前规则和单 Judge 下的参考结果，不能解释为官方 Benchmark、客观真值、生产效果或通用模型排名。运行错误不计内容 0 分；严重错误仍会阻断发布，高平均分不能覆盖严重错误。

其余本地工件仍保留在当前机器，但由 `.gitignore` 排除。若以后需要公开更多工件，应先做身份、凭据、URL、日志和许可审计，再逐项加入允许列表，不能直接解除整个 `artifacts/` 的忽略规则。
